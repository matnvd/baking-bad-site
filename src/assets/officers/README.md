# Officer headshots (optional)

Drop a square JPG or PNG here named after the officer, all lowercase with
dashes: "Vivian Li" → `vivian-li.jpg`, "Mathias Nguyen-Van-Duong" →
`mathias-nguyen-van-duong.jpg`. It appears on /team automatically; officers
without a file keep their initials badge.

- At least 400×400 px, face centered (it's cropped to the scalloped circle).
- iPhone HEIC photos must be exported as JPG first.
- Get each officer's OK before publishing their photo.
- To use a different filename, set `photo: 'file.jpg'` for that officer in
  src/data/officers.ts.
